# Рейтинг окружения

Рейтинг помогает быстро оценить окружение торговой точки по шкале от `0.1` до `9.9`. Это прозрачная оценка доступной инфраструктуры и конкуренции, а не прогноз выручки или гарантия успеха бизнеса.

## Что влияет на результат

- категории объектов вокруг точки;
- их пешеходная удалённость по OSRM;
- вес, радиус и насыщение категории;
- профиль типа бизнеса;
- количество прямых конкурентов;
- полнота доступных наборов данных.

PostGIS предварительно выбирает объекты по прямому расстоянию, после чего API уточняет маршруты через OSRM. Полезная инфраструктура повышает оценку, а прямые конкуренты уменьшают её. Влияние объектов одной категории насыщается, поэтому большое число одинаковых объектов не увеличивает рейтинг бесконечно.

## Когда рассчитывается рейтинг

Первый рейтинг создаётся атомарно вместе с точкой. Затем API добавляет новые значения по расписанию; по умолчанию — первого числа месяца в 03:00 `Europe/Moscow`. Неудачный расчёт не заменяет последнее успешное значение.

Mini App показывает текущую оценку и историю. Старые результаты не пересчитываются после изменения формулы, поэтому история отражает значения, реально полученные в каждый момент времени.

## Ограничения

Модель оценивает инфраструктуру, конкуренцию и пешеходную доступность. Аренда, выручка, население, трафик внутри помещения и качество конкретного бизнеса относятся к коммерческому анализу за пределами Smart Score. Коэффициенты зафиксированы в `rating.yml` и одинаково применяются ко всем точкам Санкт-Петербурга.

Формула, параметры `rating.yml`, обработка OSRM, confidence, breakdown и тесты описаны в [технической документации рейтинга API](../api/docs/rating.md).
