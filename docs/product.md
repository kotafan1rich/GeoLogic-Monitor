# Продукт и пользовательский сценарий

GeoLogic помогает владельцу небольшого заведения в Санкт-Петербурге своевременно узнать о новом конкуренте или завтрашнем мероприятии рядом. В целевом MVP MAX Mini App показывает текущий рейтинг окружения и историю его изменений. API для добавления, просмотра и удаления точек, текущего рейтинга и его истории реализован; frontend Mini App и автоматический пересчёт пока не реализованы.

## Действия в Mini App

- «Добавить точку» — выбрать тип бизнеса, ввести адрес и выбрать найденный вариант.
- «Мои точки» — посмотреть адреса, типы бизнеса, последний рейтинг и время расчёта.
- «Рейтинг» — открыть текущий рейтинг и график истории; по умолчанию за последние три календарных месяца, период задаётся числом месяцев.
- «Удалить» — удалить выбранную точку.

После выбора адреса API проверяет окружение, уточняет пешеходные расстояния через OSRM, рассчитывает рейтинг и атомарно сохраняет точку. Mini App сообщает «Точка добавлена» и показывает «Рейтинг окружения точки: N»; дополнительная кнопка подтверждения не нужна. Если адрес не найден, пользователь уточняет запрос. При ошибке сохранения или недоступности OSRM Mini App сообщает об ошибке, а точка не создаётся.

Типы бизнеса загружаются из справочника; начальные варианты — кофейня, кафе, ресторан. Можно добавить несколько точек. Незавершённая форма Mini App не сохраняется на сервере; сохранённые точки и история доступны при повторном открытии. История удаляется вместе с точкой.

Бот обрабатывает только технический `/start`: регистрирует личный чат для уведомлений, отправляет приветствие и предлагает открыть Mini App. Добавление, просмотр и удаление точек через диалоги бота не предусмотрены. Если чат ещё не зарегистрирован, Mini App предлагает запустить бота.

После реализации планировщика API будет пересчитывать рейтинги всех точек по расписанию: по умолчанию 1-го числа каждого месяца в 03:00 Europe/Moscow. При ошибке сохраняется прежний рейтинг и его дата; история содержит только успешные расчёты. Ручного пересчёта и уведомлений об изменении рейтинга нет.

## Уведомления

Пример конкурента:

```text
⚠ Новый конкурент

Рядом с вашей точкой на Невском проспекте, 28 открылась Coffee X.
Пешком: 420 м, около 6 минут.

Почему:
• та же категория бизнеса
• открылась вчера
• находится в пешей доступности
```

Пример мероприятия:

```text
🎵 Завтра в 19:00 концерт

Рядом с вашей точкой на Невском проспекте, 28.
Пешком: около 8 минут.

Рекомендуем:
• проверить запас продукции
• учесть вечернюю нагрузку при планировании смены
```

Уведомления не содержат рейтинг. Направление и ограничения шкалы рейтинга, описаны в [расчёте рейтинга](impact-engine.md).

История уведомлений, редактирование и пауза точек, настройка радиуса пользователем и другие города в MVP отсутствуют.
