# GeoLogic Monitor Mini App

Mini App — пользовательский интерфейс GeoLogic Monitor внутри MAX. Через него предприниматель добавляет торговые точки, просматривает текущий Smart Score и историю его изменений, а также удаляет больше не нужные точки.

Приложение не хранит продуктовые данные и не рассчитывает рейтинг. Оно получает подписанные данные запуска от MAX и обращается к пользовательским методам API.

## Место в системе

```text
MAX ── initData ──→ Mini App ── /api/v1 + X-Max-Init-Data ──→ API
                         ↑                                      ├── PostgreSQL/PostGIS
                         └──────── данные точек и рейтинга ─────┘
```

[Контейнерная диаграмма системы](../docs/diagrams/rendered/c4-containers.svg)

## Возможности

- запуск только из MAX с доступными `initData`;
- просмотр списка точек и текущего Smart Score;
- просмотр истории рейтинга за три месяца и изменения с прошлого расчёта;
- добавление точки по названию, категории и адресу;
- поиск адреса по подсказкам или геолокации устройства;
- подтверждение данных перед созданием точки;
- удаление точки с подтверждением;
- обработка загрузки, ошибок API, повторных запросов и истёкшей сессии.

## Быстрый запуск

Для запуска интерфейса вместе с API из корня репозитория:

```bash
cp api/.env.template api/.env
docker compose up --build -d postgres osrm api miniapp caddy
```

Mini App доступно по адресу <http://localhost/>, API — по адресу <http://localhost:8080/>. Без корректных MAX `initData` приложение покажет экран с предложением открыть его через MAX; это ожидаемое поведение.

Для разработки интерфейса напрямую:

```bash
cd miniapp
npm ci
npm run dev
```

Vite опубликует приложение на <http://localhost:5173/> и будет проксировать `/api` на <http://127.0.0.1:8080>. Другой адрес API можно задать в локальном файле `.env.local`; подробности приведены в [инструкции по разработке](docs/development.md).

## Проверки

```bash
cd miniapp
npm run lint
npm run build
```

Команда `lint` выполняет строгую проверку TypeScript, а `build` дополнительно собирает production-версию Vite. Автоматических компонентных и end-to-end тестов в Mini App пока нет.

## Текущее состояние и ограничения

- Основные сценарии точек, рейтинга и истории реализованы.
- Полноценная авторизованная проверка возможна только с актуальными MAX `initData` и запущенным API.
- Навигация не отражается в URL: обновление страницы возвращает пользователя на главный экран.
- Черновик добавления точки хранится только в памяти вкладки.
- История всегда запрашивается за последние три месяца; пользователь не может изменить период.
- Уведомления в MAX в интерфейсе помечены как планируемая возможность, поскольку producer в `ingestion` ещё не реализован.
